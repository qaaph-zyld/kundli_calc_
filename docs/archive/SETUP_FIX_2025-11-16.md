# Dependency Fix and Backend Setup (2025-11-16)

## Issues Resolved

### 1. Missing `pyyaml` Package
- **Problem:** `backend/app/main.py` imports `yaml` to load OpenAPI schema, but `pyyaml` wasn't in `requirements.txt`
- **Fix:** Added `pyyaml>=6.0.0` to `requirements.txt`

### 2. Swiss Ephemeris Package Name
- **Problem:** `requirements.txt` specified `swisseph>=2.10.0` but the correct PyPI package is `pyswisseph`
- **Fix:** Changed to `pyswisseph>=2.10.3.2` in `requirements.txt`
- **Note:** The import statement `import swisseph as swe` remains correct (pyswisseph installs as the `swisseph` module)

## Installation Steps

From the project root with `.venv` activated:

```powershell
# 1. Ensure virtual environment is activated
.\.venv\Scripts\activate

# 2. Install/upgrade all dependencies
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

# 3. If pyswisseph still fails on Python 3.13, install from wheel or use Python 3.11
# Option A: Try installing pyswisseph separately
python -m pip install pyswisseph

# Option B: If above fails, you may need Python 3.10 or 3.11 for full compatibility
```

## Starting the Backend

```powershell
# From project root with .venv activated
python -m uvicorn backend.app.main:app --reload --port 8000
```
